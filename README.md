# Gemeindelotterie für Bürger*innenräte

Erklärwebsite zum Paper "City Sampling for Citizens' Assemblies".

🌐 [julia-huette.github.io](https://julia-huette.github.io/)


## Dateien

- `index.html` — Hauptseite mit Erklärung (Grundproblem, bildliche Darstellung, Lösung)
- `spiel.html` — Interaktives Spiel zum Ausprobieren
- `*.png` — Bilder für die Erklärseite
- `*.mp4 / *.webm` — Animationen für den Algorithmus (Greedy Equal)
